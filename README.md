# 🚀 NextWave - Enterprise Landing Page

HTML, CSS, JavaScript(Vanilla JS)만으로 구현된 모던 엔터프라이즈 테크 기업 정적 웹페이지입니다.

## ✨ 주요 기능
- **다크 / 라이트 모드**: 사용자의 OS 환경설정 감지 및 `localStorage` 영구 저장 지원
- **반응형 디자인**: 모바일, 태블릿, 데스크톱 완벽 대응
- **숫자 카운팅 애니메이션**: `IntersectionObserver` 기반 실시간 지표 카운터
- **고객사 리뷰 슬라이더**: 순수 JS로 구현된 자동 전환 캐러셀
- **상담 문의 폼 유효성 검사**: 실시간 입력값 검증 및 토스트 팝업 인터랙션

## 🛠️ 기술 스택
- **HTML5** (Semantic Markup)
- **CSS3** (CSS Custom Variables, Flexbox, CSS Grid, Glassmorphism)
- **JavaScript** (ES6+ Vanilla JS)

## 💻 실행 방법
별도의 빌드나 의존성 설치 없이 `index.html` 파일을 브라우저로 열면 즉시 실행됩니다.
```bash
open index.html
```
